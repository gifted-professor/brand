# 一、先把“成功”和“失败”分清楚

这60例不是简单地分成“成功30个、失败30个”，而是分成下面五类：

| 分类          | 数量 | 可以据此判断什么                | 不能据此判断什么    |
| ----------- | -: | ----------------------- | ----------- |
| **销售表现有据**  | 15 | 有销量、销售额、出货或明确售罄信息       | 不代表双方都盈利    |
| **合作延续有据**  |  7 | 合作形成重复系列、跨年产品或持续机制      | 不代表每一期都成功   |
| **产品机制参考**  | 20 | 产物确实落地，值得研究其设计和合作方式     | 商业效果不足以判定   |
| **商业受挫**    |  5 | 有销售低于预期、停止产品或经济模式不持续的证据 | 未必能确认唯一失败原因 |
| **风险与混合结果** | 13 | 出现履约、声誉、授权、治理或退出问题      | 不能一概说成卖不动   |

**以下“机制”和“原因解释”是我的研究判断；销量、停止合作等事实则单独列出。**

还有一个很容易忽略的问题：**联名对双方的影响并不一定对称。** 品牌联盟研究发现，消费者对合作的评价会反过来影响各个参与品牌，而且双方受到的影响不必相等。因此，不能只给“这个组合”打一个总分，还要分别看A和B的收益与风险。([Sage Journals][1])

### 这里最值得深入研究的不是“谁卖得最多”，而是三种不同的成功结构

**第一种：让消费者以更低成本接触原本难以接触的品牌。**
瑞幸×茅台、H&M×设计师、MoonSwatch，都适合研究这种结构。但要验证的是：消费者究竟在购买产品、品牌体验，还是一次社交谈资。([Luckin Coffee Inc.][2])

**第二种：把对方的能力变成产品本身的改进。**
华为×Leica、Taco Bell×Doritos值得放在一起研究：前者涉及影像能力，后者涉及味觉与食品结构。我的判断是，这类合作更应该先做产品测试，再做传播设计。([Huawei][8])

**第三种：直接创造一条新的经营渠道。**
Sephora×Kohl’s、Nestlé×Starbucks的分析重点应是店级收益、分销、投资回收、授权和持续需求，而不是单次话题量。([科尔士企业][13])

### 这20例可以抽象成什么？

我建议你的创意机制库至少支持以下几种产物，而不只是“联名款商品”：

**新配方、新功能、设计系列、收藏周边、沉浸空间、联合内容、会员权益、渠道产品。**

一个候选合作可以同时有几种产物，但必须区分：

> **哪个是消费者真正付钱买的主商品，哪个负责传播，哪个负责转化，哪个负责后续留存。**

例如，定制主机可能是抽奖赠品，而不是零售新品；限量住宿可能主要服务传播，而不是靠房费回本。把这些混在一起，后续评价就会失真。([XBOX Wire][34])

# 四、失败案例：先看有明确商业受挫证据的5个

## 1. 麦当劳×Krispy Kreme：渠道看起来互补，但一方的账算不过来

**最终产物：**在麦当劳门店销售Krispy Kreme甜甜圈。

**已知结果：**双方宣布合作于2025年7月2日结束，曾覆盖约2400家麦当劳门店。共同声明里，麦当劳表示合作达到自身及加盟商的预期；Krispy Kreme则表示，未能让成本与单店需求相匹配，因此无法持续。([商业电讯][42])

这对你的研究框架非常重要：

**“A觉得不错”与“B赚不到钱”，可以同时发生。**

我的分析是，这类合作必须具体算到：每店每天卖多少、每次配送多少、配送频率、保质期、报损、店员操作成本和供应方毛利，而不是停留在“麦当劳有门店、甜甜圈品牌有产品，所以天然互补”。

**应提炼的失败标签：双边收益失衡、单店需求不足以覆盖服务成本、渠道扩张过早。**其中“成本无法匹配需求”有官方依据，其他标签是需要进一步验证的解释。

---

## 2. adidas×Ivy Park：粉丝数量没有转化为预期销量

**最终产物：**Ivy Park运动休闲服饰与鞋履。

**已知结果：**《华尔街日报》报道，2022年销售额约4000万美元，而内部预期约2.5亿美元；2023年双方结束合作。数字属于媒体报道口径，不是完整公开财报。([The Wall Street Journal][43])

**可以确认的是销售显著低于预期，不能直接确认的是“到底因为贵、款式、渠道，还是购买频率”。**

真正要调研的应该是：粉丝喜欢人物，还是喜欢其服装设计？愿意买一次，还是会持续买？在真实售价下，会选联名款还是其他运动品牌？

**应提炼的失败标签：把影响力当需求、销售预测缺乏验证。**

## 3. Target×Neiman Marcus：合作阵容很强，具体商品却没有打中购物任务

**最终产物：**24位设计师参与的约50款节日礼品，涵盖家居、配饰和服装。

**已知结果：**公开报道记录销售表现不佳，上市后较快折价清货。([Target Corporation][44])

我的优先解释是：**品牌组合本身有吸引力，不代表具体品类、价格和节日购物需求也匹配。**这应通过SKU数据和消费者拒购访谈验证，而不是简单归结为“高端与大众不能合作”。

它与H&M设计师系列适合配对研究：同样跨价格层级，为什么消费者对某些具体产品有明确购买理由，对另一些没有？

**应提炼的失败标签：品类与价格错配、合作名气替代选品判断、库存风险。**

---

## 4. Beyond Meat×PepsiCo：赶上趋势，也不代表产品经济性成立

**最终产物：**合资合作中的Beyond Meat植物肉干。

**已知结果：**2024年报道公司停止该产品，属于改善成本和利润率的调整。([Reuters][45])

适合研究的问题是：消费者会不会复购？制造难度和成本是多少？渠道增加后，新增收入是否足以覆盖生产与服务成本？

**应提炼的失败标签：趋势替代需求验证、单位经济不成立。**但不能把Beyond Meat整家公司的业绩问题全部归给这款产品。

---

## 5. 麦当劳×Beyond Meat美国McPlant试点：宏观趋势没有变成当地门店需求

**最终产物：**美国试点的McPlant植物肉汉堡。

**已知结果：**美国测试结束；2024年麦当劳美国负责人表示，当地试点没有获得足够消费者需求。这个结论不能外推为所有国家的McPlant都失败。([Business Insider][46])

**应提炼的失败标签：地域错配、使用场景错配、把品类趋势当成当地购买需求。**

# 五、另外13个风险案例：有的卖得好，但合作仍然出了问题

这些案例尤其适合做你的**风险预警库**。

| 案例                        | 实际产物与发生的问题                                                               | 应提炼的警示                                       |
| ------------------------- | ------------------------------------------------------------------------ | -------------------------------------------- |
| **C18 IKEA×Sonos**        | 家具音箱多年迭代后，2025年停止后续合作并逐步售完库存。([IKEA][47])                                | **退出与售后**：合作结束不自动等于亏损；联网产品还要处理软件和支持责任。       |
| **C38 adidas×Yeezy**      | 鞋服系列前期热销；2022年因Ye反犹言论终止。最后库存于2024年第四季度售完。([阿迪达斯集团][48])                  | **人物与声誉风险传导**：销量成功不能消除集中依赖和退出风险。             |
| **C40 Gap×Yeezy**         | 连帽衫、外套等；2022年先发生履约与治理争议，之后撤下剩余产品。([Reuters][49])                         | **合同和决策权**：分销、门店、创意控制要明确。Ye方违约指称不是已被法院证实的事实。 |
| **C45 LEGO×Shell**        | 积木促销合作；环境组织施压后，LEGO宣布到期不再续约。([Reuters][50])                              | **价值观关联风险**：对方的公共争议可能影响自己的品牌。不是已经证明玩具卖不动。    |
| **C46 喜茶×景德镇中国陶瓷博物馆**     | “佛喜”饮品及相关包装；媒体报道被约谈，联名随后下架。([新京报][51])                                   | **文化语境审查**：能合作，不等于每一种商业表达都合适；不能把约谈直接写成已认定违法。 |
| **C47 乐乐茶×译林出版社**         | “烟腔乌龙”、鲁迅画像杯袋和立牌；2024撤文宣并致歉，2026又就画像著作权侵害认定后的使用问题致歉。([m.gmw.cn][52])     | **逐素材授权**：出版社合作不自动覆盖画像作者的权利。不同权利问题必须分开。      |
| **C48 Gucci×adidas**      | 联名伞具明示不防水，引发讨论。([Business Insider][53])                                  | **功能预期错位**：装饰定位与“伞”的消费者预期可能冲突；舆论争议不是销量失败证据。  |
| **C49 麦当劳×BTS**           | 主题套餐与包装；印尼部分门店因拥挤短暂关闭。([Reuters][54])                                    | **需求过强也有风险**：粉丝峰值、取餐分流、门店容量要提前设计。            |
| **C50 奈雪×薄盒「范特西音乐宇宙」**    | 主题茶饮、包装及数字互动；消费者对是否为周杰伦本人合作存在理解争议。([证券时报][55])                           | **授权对象与传播对象一致**：不能把项目授权直接表述为艺人本人代言。          |
| **C57 Target×Missoni**    | 服装、家居等系列需求强，但网站崩溃，部分订单延误或取消。([MPR News][56])                             | **成交不等于交付**：不能用售罄掩盖消费者没收到货。                  |
| **C58 KFC×《原神》**          | 套餐、徽章等；2021年上海、杭州部分线下活动因聚集等原因取消。([PlayStation LifeStyle][57])            | **赠品就是核心履约**：不能把周边当作“不重要的附赠”。也不能说全国联名全部失败。   |
| **C59 HTC／AT&T×Facebook** | 预装Facebook Home的HTC First；合约价快速下调，英国上市暂缓。([The Wall Street Journal][58]) | **喜欢应用不等于需要整部专用手机**：技术合作也必须验证用户任务。           |
| **C60 Apple×U2**          | 专辑自动加入iTunes用户曲库，引发反感，Apple后来提供移除工具。([Pitchfork][59])                    | **免费也需要选择权**：能触达所有用户，不代表所有用户都需要。             |

### 失败库不应该只有“失败原因”一列

我建议至少拆成：

**发生了什么 → 哪个环节失效 → 哪一方受损 → 原因证据有多强 → 当时能否提前发现 → 应该设置什么检查。**

比如：

* **麦当劳×Krispy Kreme**，核心检查是双方经济账与单店成本。
* **乐乐茶×译林**，核心检查是每一张图的授权链。
* **Target×Missoni**，核心检查是库存、支付和交付系统。
* **Apple×U2**，核心检查是用户选择与退出设计。

它们不是同一种“品牌不匹配”。([商业电讯][42])

# 六、真的有两个品牌要联名，应从哪些维度分析？

下面这20项，是我建议你采用的完整框架。**它不是只评价创意，而是从合作意愿一直检查到交付、利润和退出。**

| 维度                 | 核心问题                                  | 必须形成的研究产出               |
| ------------------ | ------------------------------------- | ----------------------- |
| **1. 双方目标**        | A和B分别要销量、拉新、提价、认知、渠道还是会员？目标冲突时谁优先？    | **A/B分别列目标、指标、底线与时间。**  |
| **2. 品牌定位与边界**     | 消费者如何理解两个品牌？哪些形象、承诺和价格预期不能被破坏？        | 品牌认知图、可借用资产、禁用清单。       |
| **3. 实际资源与权属**     | 每方到底提供技术、IP、设计、原料、场地、预算还是渠道？资源真的可用吗？  | 资源—负责人—权利—交付物矩阵。        |
| **4. 受众分层与重合**     | 谁是A老客、B老客、共同客和潜在新客？购买力、偏好和使用频率如何？     | 四组受众画像，而不是两个“年轻人”标签。    |
| **5. 可转化的新客**      | 谁本来不会来，但会因为这次合作来？我们真的能触达他吗？           | 新客来源、触达路径、转化假设与验证方法。    |
| **6. 真实需求与场景**     | 在什么时间、地点、任务中使用？相比现有商品解决了什么？           | 场景—问题—替代方案—新价值说明。       |
| **7. 功能互补与故事合理性**  | 两种品牌资产为什么应该结合？消费者能否一句话讲清楚？            | 分别写功能价值和情感价值，避免只说“反差感”。 |
| **8. 最终产物组合**      | 主商品、包装、周边、体验、内容、会员权益分别是什么？            | 产物树、SKU清单、主次关系与库存规则。    |
| **9. 价格与支付意愿**     | 溢价来自哪里？真实价格下，消费者会买它还是替代品？             | 净成交价、价格阶梯、分群价格测试。       |
| **10. 渠道与转化**      | 看见以后到哪里下单？谁负责支付、配送、取货和售后？             | 从曝光到复购的完整路径及归因入口。       |
| **11. 供应链与峰值履约**   | 起订量、产能、交期、保质期、补货、赠品能否承接？              | 备货计划、容量上限、缺货与延期方案。      |
| **12. 技术、数据与选择权**  | 是否关联账户和会员？谁处理数据？如何知情、退出与获得支持？         | 数据流、权限、用户同意与退出设计。       |
| **13. 双边经济与现金**    | A和B分别赚什么、付什么、垫多少？卖不完时谁承担？             | 两份损益、内部收费抵销、现金峰值、三种情景。  |
| **14. 授权与合同**      | 商标、人物、画像、音乐、字体、设计分别由谁授权？覆盖哪里、多久、什么品类？ | 逐资产授权表、审批权、责任与退出条款。     |
| **15. 文化、声誉与合规**   | 有没有容易被误读的表达？是否涉及特殊敏感内容、产品安全或环保声明？     | 风险分级、不可接受事项、暂停和回应方案。    |
| **16. 合作意愿与治理**    | 谁能拍板？预算和资源是否获批？谁有权改设计、改价格、停卖？         | 决策人、责任表、审批期限与升级机制。      |
| **17. 档期与生命周期**    | 热度窗口与研发、审批、生产周期是否冲突？                  | 关键路径、最迟决策点与替代档期。        |
| **18. 竞争、排他与替代方案** | 对方最近和谁合作？有什么排他限制？自己做或换伙伴是否更好？         | 候选比较、独立开发基线、排他代价。       |
| **19. 效果衡量与增量归因**  | 如何排除折扣、开店、季节和其他投放的影响？                 | 指标口径、对照设计、数据负责人。        |
| **20. 长期资产与退出**    | 项目结束留下什么？剩余库存、内容许可、软件和售后怎么办？          | 续做／停做条件、资产归档和退出计划。      |

这里面，**第4项“受众相似”与第5项“新增客户”必须分开。**

两家客群高度重合，可能容易卖，但新增用户有限；客群完全不重合，也可能根本没有购买理由。你的系统不应该默认“越像越好”，而应该回答：

> **在哪个共同场景里，一方现有客户会因为另一方提供的价值，愿意采取一次新的行动？**

# 七、最容易被做浅的五项，具体应该怎样调研？

## 1. 用户研究：不要只问“你喜欢这个联名吗？”

我建议至少覆盖四组：**A的客户、B的客户、双方共同客户、双方都不是但可能购买的人。**

比“你喜欢吗”更有用的问题是：

“最近一次买这类商品是什么时候，花了多少钱？”
“在这个价格下，你选原商品、联名款，还是都不买？”
“拿掉赠品，或者拿掉Logo，你还会买吗？”
“你认为两家品牌分别做了什么？”
“买完第一次，什么条件会让你再买？”

这些问题分别帮助区分：真实需求、价格接受度、收藏需求、合作认知和复购条件。

**尤其是IP联名，必须把“喜欢角色”“想要赠品”“愿意长期消费主商品”分开记录。**

---

## 2. 产品研究：至少比较三个方案

不要只拿一个很好看的联名概念去问用户。

我建议比较：

**原商品 → 不联名但改良的商品 → 联名商品。**

尽量控制价格、基本质量和展示方式。这样才有机会区分：消费者是因为产品改良而购买，还是因为合作品牌而购买。

例如，一款新品本来就更好喝，那么销量提升不能全部归到联名；一款产品拿掉联名标识仍然很受欢迎，说明其价值可能主要来自产品本身。这是你设计测试时需要分开的解释。

---

## 3. 经济研究：必须分别做A和B的账

建议采用这个基本结构：

> **某一方的增量贡献利润**
> ＝联名相关净收入
> －本方新增的生产、履约、授权、投放、运营等成本
> －被挤占的原业务贡献利润。

然后再检查双方内部往来：A支付的授权费，可能正是B的收入；A向B采购的货款，也不能在项目合计中被重复当成对外收入。

还要单独检查**现金峰值**：一个项目最终可能赚钱，但前期库存、保底授权和投放垫资，已经超出某一方能承受的范围。

以品牌认知为主要目标时，短期不盈利可以是被批准的营销投入；但预算上限和有效结果必须事先确定，不能事后用“品牌价值”解释所有超支。

---

## 4. 授权研究：不是“有合作协议”就结束

应将素材拆成独立对象审核：

**品牌名称、商标、角色、人物形象、具体画像、音乐、字体、摄影、设计文件。**

每个对象都核对权利方、许可品类、地域、期限、使用媒体、能否改编、能否转授权，以及结束后库存和内容如何处理。

乐乐茶案例尤其适合说明：**与出版机构合作，和取得某一幅人物画像的商业使用权，是不同的问题。**其2026年声明涉及的正是具体画像的著作权权益。([m.gmw.cn][52])

实际项目需要由相应法域的法务核验，不能仅依赖AI或品牌代理商的口头确认。

---

## 5. 效果研究：不要把“活动期间卖了多少”直接当增量

至少同时记录四组结果：

| 结果层次   | 应关注的指标                     |
| ------ | -------------------------- |
| **传播** | 有效触达、合作认知是否正确、品牌态度变化       |
| **交易** | 净成交、原价售出率、完成交付率、退款与投诉      |
| **经营** | 双方增量贡献、库存报损、现金占用           |
| **长期** | 真正新增客户、联名结束后的复购、会员活跃及可复用资产 |

条件允许时，可以采用试点门店与对照门店：

**初步增量估计＝试点门店前后变化－对照门店前后变化。**

但前提是趋势可比，没有其他重要同步差异；能随机分配、控制促销和渠道串扰更好。对照不足时，结论应保留不确定性，而不是直接宣布“联名贡献了全部增长”。

# 八、怎样把研究转成“这两个品牌值不值得做”的判断？

我建议用 **“硬门槛＋匹配评分＋证据覆盖＋试点”**，不要只用一个匹配分。

## 第一层：先检查硬门槛

权利链无法确认、产品安全存在不可接受风险、现金损失超出承受范围、关键资源没有承诺、严重排他冲突等问题，**不能被一个很高的创意分抵消。**

硬门槛没有核验，不代表默认通过。

## 第二层：再评估匹配质量

工作簿提供了12项、总权重100的评分卡，包含目标、需求、增量受众、品牌叙事、能力互补、产品价格、渠道、供应链、经济性、治理、衡量与复用。

每项按0—5评分：

**总分＝各项“权重×评分÷5”之和。**

这些权重是可调整的工作建议，不是行业公认标准。

## 第三层：把分数和证据分开

“看起来85分，但多数依据来自猜测”，与“75分，关键假设已经被用户测试和报价确认”，不是同一种项目。

因此，评分卡单独计算**已验证证据所覆盖的权重比例**。

表里设置了75分、60分和80%证据覆盖等可编辑参考门槛，用于安排“进入试点、继续验证、重新考虑”，**不是预测成功概率，更不是批准直接大规模铺货。**

## 第四层：用试点解决剩余未知

对第一版合作，我建议优先验证最可能致命的假设：

产品没人愿意付钱，就先测价格与购买；
双方成本不清楚，就先拿报价和小批量履约数据；
用户主要冲赠品，就先验证赠品供应和主商品复购；
权益涉及账户关联，就先验证用户理解、使用与退出。

**试点的目的不是做一个小一点的发布会，而是尽快弄清：这次合作最可能错在哪里。**

---

# 九、这个“大集合体”最终应该怎样组织？

我建议底层至少分成八类数据，而不是一张越来越长的品牌表：

| 数据对象     | 记录什么                      |
| -------- | ------------------------- |
| **品牌**   | 定位、价格、受众、资源、边界、来源与更新时间    |
| **合作项目** | 目标、时期、地区、类型、阶段和状态         |
| **参与方**  | 每一方的角色、投入、收益、责任、审批与限制     |
| **最终产物** | 商品、赠品、体验、内容、权益；区分原型与正式售品  |
| **效果指标** | 数值、单位、时间、地区、分母、口径与来源      |
| **证据来源** | 哪条事实由哪个原始来源支持，有无独立交叉验证    |
| **风险事件** | 事件、原因证据、受损方、后续纠正和最终结果     |
| **匹配研究** | 两个品牌的合作假设、依据、未知项、评分和下一步测试 |

这样，它以后才能回答不只是“谁和谁联过”，而是：

**“有没有相似客群但不同渠道的案例？”**
**“哪些合作把对方技术真正放进了产品？”**
**“哪些项目卖得很好，却因为履约或授权出问题？”**
**“这个组合最像哪三个成功机制，又接近哪两种失败路径？”**

尤其要保留**反证和未知项**。没有披露利润，就写没有披露；只有首发售罄，就不要自动生成“长期商业成功”；后续出现判决、解约或库存结局，就追加时间线。

最后，真正比较两个品牌时，研究报告应该能落到这一段话：

> **A希望通过本次合作获得什么，B希望获得什么；双方用哪些真实资源，为哪类人在什么场景下创造什么产物；为什么用户会愿意付钱或参与；双方如何承担成本、取得收益；最危险的假设是什么；用什么试点验证，什么情况下停止。**

**能够把这段话用证据填完整，才算完成了一次品牌联名调研。仅仅生成一个好看的联名概念，还只是其中的创意环节。**
