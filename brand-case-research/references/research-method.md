# 调研方法：从案例到可迁移机制

## 20 个维度

以下来自用户提供的 GPT 工作簿 `20项调研维度!A6:G25`，是工作框架。选当前问题相关维度，不要求资料不足的历史项目填满。

| 编号 | 维度 | 要得到的结论或缺口 |
|---|---|---|
| D01 | 双方目标与成功标准 | 分别写 A/B 目标、优先级和期限 |
| D02 | 品牌定位与边界 | 核心承诺、价格层级、不可变元素 |
| D03 | 真实资源与权属 | 每方能提供什么，谁确认，许可范围 |
| D04 | 受众分层与重合 | A 独有、B 独有、共同客、双方非客户 |
| D05 | 可转化增量受众 | 可触达与可转化是否有证据 |
| D06 | 需求与使用场景 | 消费者任务、替代方案和参与时机 |
| D07 | 功能互补与叙事 | 消费者能否讲清双方各自贡献 |
| D08 | 最终产物与产品组合 | 主产品、包装、赠品、空间、内容、权益 |
| D09 | 价格与支付意愿 | 净成交价、溢价来源、拒购证据 |
| D10 | 渠道与转化路径 | 看见、购买、取货、售后、复购 |
| D11 | 供应链与履约 | 产能、保质期、补货、峰值与库存 |
| D12 | 数据、技术与选择 | 数据流、系统依赖、用户知情与退出 |
| D13 | 双边经济与现金 | 分别收益、成本、损失承担与现金节奏 |
| D14 | 授权链与合同 | 每项素材、地域、期限、品类、媒体 |
| D15 | 文化、声誉与监管 | 具体受众反应、已知事件与未确定判断 |
| D16 | 意愿与治理 | 决策人、责任、审批与争议处理 |
| D17 | 档期与生命周期 | 工期、营销窗口、最迟决策点 |
| D18 | 竞争、排他与替代 | 不合作或换伙伴的可比较基线 |
| D19 | 测量与增量归因 | 指标口径、基线、对照与混杂因素 |
| D20 | 长期资产与退出 | 库存、售后、许可到期、内容和经验复用 |

## 机制提炼

用“投入 → 用户任务 → 产物 → 收益路径 → 适用条件 → 不能照搬”组织分析。将原料共创、技术共研、内容体验、渠道互通、身份表达、收藏机制分别看待。机制标签用来检索，不能替代具体说明。

示例分析方式：咖啡与书店可以研究“现有饮品＋选书内容＋到店阅读”的体验路径；如果当前 brief 禁止新增印刷，就寻找数字内容或现有资源的表达。不能因为历史热门案例用了杯套，自动给当前设计新增杯套。此例是假设性方法演示，不是入库事实。

优先检索相似消费者任务与资源条件，再比较行业/品牌。给创意提供相关机制、失败或混合结果，以及迁移差异；案例数量随任务调整，不凑固定数量。包材视觉、内容权益或数字体验是否足够，应由消费者价值和当前限制判断，不把“必须有新实物”作为通用规则。

## 事实核验

先查最会影响决定的主张：项目是否存在、实际产物、关键时间/市场、核心数字、退出或更正。来源能证明“企业这样披露”，不一定证明利润、增量或因果。维护传播、交易、经营、长期结果四类指标，避免把整体公司增长归因于单次合作。

用报告差异生成补证问题。例如：“售罄”需要批次规模；“千万级抢购”需要明确是访问、排队、订单还是出货；“库存积压”需要当时日期及后续处置；约谈、下架、行政处罚、违法认定不能互换。

Gemini 报告提出的 ROI 阈值、48 小时补货、特定品类绝不合作、无条件解约等，保存为作者建议或合同研究议题。它们没有随附可核查来源，不能自动变成创作约束、法律结论或已生效权利。

## 用户研究与反例

先问近期真实购买经历，再问概念；比较原商品、非联名改良商品与联名商品时尽量控制价格、品质、促销和渠道。区分粉丝偏好、支付意愿和实际购买。前后变化需检查季节、开店、折扣等混杂因素；没有对照不宣称因果。

跨案例总结附适用边界和反例。品牌双方受益可能不对称；合作持续可能源于战略安排；终止也不必然等于整个生命周期亏损。
