# 联名故事与宣传文案

## 输入与输出

可从 researchContext 参考叙事结构和受众表达；不得移植历史案例的销量、价格、档期或合作承诺。当前文案的事实范围仍由 DesignSpec 决定。

输入为有效 DesignSpec、当前文案和语气要求；输出 CopyPack。先阅读 [契约](references/CONTRACT.md)。整套请求另按 [整套物料交付约定](../visual-production/references/CAMPAIGN_KIT.md) 保存故事线、逐件文案和视频脚本附件；保留现有 CopyPack 字段，story 只是概要，不冒充完整故事线。

## 步骤

1. 从实际可用上下文取得当前设计引用、哈希和用户修改范围；逻辑工具可用时调用 mcp__collider__get_context，不编造工具结果。
2. 保留已经确定的产品身份、双方贡献和真实待确认项。
3. 输出 title、slogan、story、posterTitle、posterSubtitle、socialCaption。
4. 标题说清联名或消费场景，故事解释具体设计，不使用空泛套话代替创意。
5. 保留 disclosure，提交 CopyPack 并引用当前 designRef。

## 整套故事与逐件文案

先形成能展开的叙事：一句话故事、角色及动机、开端、事件与选择、转折、结局和消费者参与的位置。产品在关键情节中发挥具体作用，不能把几段品牌精神拼接为故事线。已有 IP 设定与本次原创剧情分别标记；不把原创台词写成官方台词。

随后按同一条故事线编排预热、发布、参与、分享/回访各触点；每阶段写出观众已知什么、获得什么新信息、下一步行动及承载物料。叙事可短，但应有完整因果和收束；解谜类活动另给真实线索、提示、解答与无障碍退出路径，不能只写“发生了神秘事件”。

默认在效果探索阶段，逐件输出实际文案并绑定物料 ID：主标题、正文、说明、行动引导与必要披露，按效果图实际展示的内容区控制篇幅。杯托、杯身/杯套、故事卡等不能共用一段通用海报文案充数；对故事设计有作用的内外面、正反面分别写，但不等待精确尺寸或完整印刷面表才展开创意。用户进入打样/生产阶段后再补各印刷面与精确空间适配；清单未包含的赠品不能在文案中新增。

需要为后续视频准备时，输出明确时长与分段的脚本：每段剧情作用、可见动作、人物台词或旁白、画面文字、声音提示、转场及关联物料 ID。短版与长版从同一叙事裁剪。脚本、分镜文字和视频提示词属于准备文件，不是实际关键帧或成片。

## 边界

不能新增设计中没有的礼盒、赠品、材质、活动价格、日期、销量、授权或商业合作事实。

只改宣传语时，不调用 image_generate，不更新产品配色或组件。文案长度参考当前海报模板；溢出时重写，而不是默认无限缩小字体。

用户要改产品本身或产品上的实体文字，应把修改交回 design-spec，不在 CopyPack 中偷偷改变。

## 完成条件

文案与设计一致，修改范围符合用户要求。整套请求须有完整故事、触点推进和逐件实际文案，能支撑物料效果图与视听制作；本阶段不以生产尺寸或完整印刷面校对作为前置门槛。提交后交付真实 CopyPack 引用及附件路径；工具未实现时不自报保存 ID。
