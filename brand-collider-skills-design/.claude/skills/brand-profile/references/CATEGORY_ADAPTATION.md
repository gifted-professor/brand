# 开放品类的联名适配方法

适用于新品牌、新品类，以及同一品牌换产品线、用户或场景后的重新策划。以本次资料建立适配依据，再发散核心产物与相关物料；没有行业模板也能继续。五类物料是整理结果的目录，不是先填满的创意菜单。只改文案或调整既定画面时复用有效依据，不重新扩大任务。

## 从本次业务建立画像

先弄清用户要合作的业务，而不是只辨认品牌名称。多产品线品牌可以有多个锚点：按用户指定范围、目标用户、使用任务和双方贡献选择；未指定且几个方向都有价值时，分别提出可比较的锚点，不把品牌永久绑定到一个代表单品。双方都可承载产品，也可共同提供内容、系统或服务。

把输入整理为以下适配依据，缺项按影响处理：

- **卖什么、提供什么能力**：实际产品/服务形态、可用资源、品牌辨识特征，标明来自用户资料、已读取来源还是创意假设。
- **谁在何处做什么**：具体动作、环境、购买/使用动机和关键时刻。同一服装在瑜伽、越野和通勤中需要的设计不同；行业名不能替代场景。
- **消费者接触到什么**：产品可见面、构件、接触部位、使用状态、界面或服务环节；优先找本次有设计意义的部分，不要求穷举完整工程结构。
- **什么应保留、什么可探索**：已知轮廓、功能、接口、活动空间、感官体验或流程约束；尚未核实的结构只写待确认。用户允许重新设计本体时可以探索新结构，并说明验证依赖。

品牌从未出现过但资料足够，直接按这些属性推进。只有名称且连主营业务都无法判断时，提出影响方向选择的最小问题；同时保留可做的整理。已知品类但缺少型号、面料、工艺或参数，通常仍可做明确标注假设的概念，不要求用户先提交完整供应链资料。本方法不增加联网能力：有可用检索工具才读取官方资料，没有则沿用提供资料并标未知，不能把记忆或类比写成刚刚核实的事实。

## 把双方资产变成具体设计

对有潜力的组合写出可评审的设计关系：**哪项合作资产 → 怎样改变 → 哪个产品部位或体验环节 → 在什么场景带来何种使用、审美或收藏价值**。这是设计结论，不需要展示内部推理过程。

资产既可以是形态、图案、色彩、角色、故事、文化和声音，也可以是材料、工艺、风味、技术、内容、渠道与服务。转换方式按本案自由组合，例如提取轮廓、抽象纹理、调整分区、融合材料感、互换感官特征、组合功能、设计内容或重组使用流程；这些是思考工具，不是封闭枚举，不要求每一种都使用。

设计需落到载体本身。软质穿戴品可研究剪裁、图案分区、内外层、扣件及动作状态；硬件可研究外壳、交互面、配件接口和开合状态；内容/服务可研究信息、节奏、界面与参与步骤。也可产生新的属性组合。不要因为同属“运动”就都做运动衫，因为同属“科技”就都做手机壳。

保留与使用直接相关的条件：图形或附件不应无依据地覆盖散热、摄像、握持、受力、活动或控制部位。涉及改变这些部分时，把它作为需工程确认的独立提案，同时给出在已知条件内成立的表达方案。外观概念不承诺防护等级、舒适性、材料性能、健康效果或新增软件能力。

## 在品牌相关性内充分发散

探索时可在三个距离上寻找机会，按用户意图决定广度，不要求每个项目各做一组：

1. **主营深化**：同一核心产品的外观、形态、材质感、使用或收藏表达有哪些不同解法；用户只要单品时就围绕单品深化。
2. **邻近延伸**：消费者在使用前、中、后会搭配、携带、保护、维护、展示或分享什么；这些需求能否形成适配配件、内容或服务。
3. **探索提案**：把双方能力迁移到新的品类、组合套装、空间或体验。写明它与主营或品牌资产的连接，以及新增能力/资源的假设；“现有目录没有”不等于创意不成立。

发散既可改变产品，也可改变合作机制和用户场景；不要只变配色或加一个通用赠品。用户想要大胆选择时保留有清楚连接的远距离提案，不把候选全部压成现有产品换皮。真实能力决定事实表述与待确认项，创意假设可以成为后续选择。

## 从使用旅程推导物料

沿本案真实旅程寻找有独立作用的输出：发现与理解、选购与试用、收到与打开、使用与搭配、携带与存放、维护与复用、展示与分享。它们是可选观察角度，按需要增删；不把没有的线下门店、实体包装或线上功能硬加进去。

每项候选说明对应的人、动作/触点和设计作用，再归入 product / packaging / communication / merchandise / experience。可跨多个核心产品组织同一联名系列，也可只围绕一个产物。包装、海报和周边沿用核心设计逻辑，各自解决保护、理解、销售或使用问题；不能用大批宣传图掩盖核心产品尚未设计。

需要丰富选择时以约 20–30 项为软目标，可继续扩展有独立用途的候选；用户限定单件或窄范围时缩减。同一款换颜色、角色、材质表现、尺寸或视角通常放 variants。用途、结构或使用方式确实不同才单列。核心/推荐/可选表达制作建议；它与上述探索距离不同，探索提案也可能成为选定后的核心。

当新增项只是在重复设计、重复触点或失去双方关联时停止扩张，并说明目前覆盖的范围。数量不是合格的替代指标，不给所有行业固定一套礼盒、贴纸、徽章和帆布袋。

## 保存可追踪的适配依据

研究阶段在既有研究正文中简要记录业务画像；设计统一阶段在现有 `section` 给出“本案适配依据”：选择的核心及理由、用户动作和环境、可设计部位或体验、需保留的功能、双方具体融合、扩展范围与排除理由。只写支持评审的结论，不重复全部清单。

完整业务契约使用已有事实/解释、产品想法、场景、设计描述和约束字段；网页不新增 payload、枚举或虚假的工具调用。MaterialPlan 按既有字段承接：

| 字段 | 承接内容 |
| --- | --- |
| deliveryScope | 全案用 full_collaboration；用户明确限定本轮交付且已有核心设计依据时用 focused_deliverables。后者只列所需项，不能添加虚假核心产品来凑清单；旧记录缺省按全案校验且不补字段。 |
| productAnchor | 主营或服务锚点、为什么选它、双方资产如何进入设计；多个核心可在描述及 items 中展开，承载方支持 a/b/both。 |
| scopeNote | 本案发散与收敛范围，适合哪些延伸、不适合哪些，数量和用户约束如何取舍。 |
| items[].role | 为哪个人、哪个动作/触点提供何种价值。 |
| items[].design | 具体产品部位、形态、可见面或体验状态，以及设计后的效果。 |
| items[].ipExpression | 合作资产到本件设计的具体关系；旧字段名不要求存在 IP。 |
| items[].feasibility | 哪些有依据、哪些是邻近/探索提议、哪些功能应保留、哪些条件待确认。 |
| dependencies / variants | 真实设计依赖与同款变体，避免重复物料。 |

后续文案使用这些适配结论，视觉提示词落实到对应部位和使用状态；不在后续步骤悄悄换产品线或新增功能。修改核心业务、目标用户或使用环境后重审受影响依据；纯文案修订沿用设计约束。

全案清单保留 product 或 experience 的核心项。限定范围可只有用户要求的海报、包装或周边，既有核心只是设计依据，不冒充本轮新增交付；scopeNote 必须说明用户范围与复用依据。此范围声明不能用来逃避全案的核心设计要求。网页的限定范围清单支持不等于已实现新会话跳过固定方向选择的自动路由。

## 适配复核

检查可观察的设计结果，发现问题时局部修订：

- **替换品牌**：换成同品类另一个品牌后，哪些形态、工艺、场景或内容必须改变？只改名字就全部成立，说明资料或设计还不够具体。允许共享通用物料，但核心应有可说明的差别。
- **替换场景**：换成另一种动作或环境，哪些产品选择、设计部位与物料应变化？仅改宣传词，说明没有用上场景。
- **追踪候选**：每项能否回到一个实际触点、主营或明确的探索连接？缺连接的删去、合并或重新设计。
- **检查本体**：是否明确改变了何处、保留了什么，双方是否都产生可见或可体验的贡献？包装与海报不能代替本体设计。
- **检查边界**：大胆提案是否标明新增能力假设，是否误写成已生产、已实现或性能已验证；是否为了穷举而违反用户范围。

开放适配意味着用这套方法处理新的属性组合，不意味着预先备齐无限模板或保证所有组合都能商业落地。需要对照示例时按需读取 [品类示例](../../visual-production/references/CATEGORY_EXAMPLES.md)；示例不是新行业进入流程的前提，也不替代本案资料。
