# 内部赛马：从十二个候选到成熟方案

用于首次创意或一批方向被否定后的重跑。十二是本项目默认发散规模，三是成熟方案的目标上限；用户另定规模时以用户要求为准。局部文案修改不触发重跑。

## 候选要足以比较

每项记录稳定的本地候选编号、名称、消费者最终拿到或体验到什么、双方具体贡献、参与过程、目标作用机制、可呈现的核心产物、主要失败方式和未确认资源。这是可交付的设计摘要，不是私有推理记录。

独立创作者先只看相同 brief 与事实附件。鼓励从产品、服务、内容、渠道与使用方式等不同角度出发，但不要把每个角度当作必须交付的类别。旧推荐不能自动成为种子或最终优胜者。

只有角色、名称、颜色不同的方案属于同一机制；合并重复后有明显缺口，可定向补充候选，但不得补造历史上的“独立生成”记录。

## 先找具体缺陷，再比较相对优劣

检查五个问题，并为每个判断给具体依据：

1. **为何是这两个品牌？** 产品、内容或体验中双方分别做了什么；换成任意同类品牌后损失什么。品牌识别、工艺技术或角色授权可以有价值，但不能成为没有消费者体验的唯一解释。
2. **消费者得到了什么？** 区分口味、便利、体验、表达、可负担性等实际价值，并说明为此付出的金钱、时间和操作。不要把品牌希望提高销量写成消费者价值。
3. **最终能做成什么？** 产品或体验的组成、使用方式和主场景是否明确，能否据此形成设计规格与画面。
4. **如何服务本次目标？** 从参与到结果是否有完整路径，怎样验证；意愿、购买、收入、复购和利润不能混用。
5. **缺口是否可解释？** 区分已有资源、新增提议、未知授权与结构性矛盾。提出最小试点、成本驱动和失败信号；不能默认开放游戏接口、已有优惠可叠加或所有门店都能执行。

直接违反当前硬条件、没有实际消费者所得、核心机制自相矛盾或只有泛化贴标的候选应淘汰。“只有贴标”指缺少具体产品设计与消费者价值的拼贴；审美符号、角色、配色、图形、材质、工艺、功能或内容对核心产品或体验有明确作用时，外观、风味、收藏、表达和使用本身可以构成联名价值，不强迫每个方案添加解谜、积分系统或长篇剧情。尚未取得授权或未有销量数据，不是创意探索阶段的一票否决。已有相似案例时指出本次新增了什么；不能声称没有竞品。

使用“入围／淘汰／需修订”和文字依据即可。若使用分数，明确它是设计评审尺度，不是市场数据、效果预测或成功概率；高总分不能抵消实质阻断。

## 一次收敛

分阶段调用同一 Skill 不代表每次都重做全套赛马。提出阶段拥有本轮候选池与初筛记录；收敛阶段复用它，只处理具体缺陷、差异和最终排序。没有记录的候选不能算已完成；失效时只针对已指出的缺陷补充。成熟方案在结构化 concepts 中保存一份，阶段正文记录增量决策，不重复完整正文、品牌研究或来源资料。

先固定候选池，再交给冷评者；可从消费者与品牌产品两个视角独立评价。主编依据证据裁定分歧，不按模型票数决定。保存原始候选、评审结果和改写后的映射，不把多个模型看过资料称为已完成多方案赛马。

针对具体问题做一轮改写或定向补充，再核对被指出的缺陷。最终不超过三个，必须过绝对质量门槛且机制不同。若只剩一个合格方案，就给一个并说明其他候选为什么没过。

## 成熟方案的交付要求

每个入围者至少回答：

- 核心产品或体验是什么，双方资产怎样形成具体设计或功能，包含哪些组成，消费者最终获得什么；相关包装、传播及周边从该主体和实际接触点展开。合作资产不限 IP，纯数字、内容或服务方案不强制实物。
- 从看见、参与到离开的实际过程；什么会促成下一次自愿选择。
- 双方各自贡献、收益与关键合作依赖。
- 最小可行试点，新增物料、人力、内容或系统；未知项明确标记。
- 价格原则、补贴承担与主要成本驱动；没有数据不编造销量、利润或 ROI。
- 一幅具体主视觉场景及核心传播句；它们必须表现方案本身。
- 如何测量目标、最可能失败在哪里，以及哪些信号说明需要停止或调整。

向用户展示成熟结果、推荐与取舍。候选池和评审表可展开查看，通常不占据主呈现。成品图需要后续真实生成与读图检查；一段视觉描述不是已完成的图片。

十二进三针对创意方向，不限制物料候选数量。需要丰富选择时按 CAMPAIGN_KIT 的核心/推荐/可选规则展开；范围适合时可用 20–30 项为软目标，实际能力、输入范围与有效条件决定规模，不硬套实物数量。同一物品的角色、颜色或尺寸变体不计为新项，候选计划不等于已授权全部生图。

## 记录与宿主边界

赛马记录作为内部工作附件或宿主支持的审计数据保存，引用真实文件及内容哈希；不发明已注册的新工具、ArtifactRecord ID 或 ReviewReport 阶段。中央和局部契约定义成熟 ConceptSet；当前网页是否具备结构化候选池与独立评审编排，需要由实现与执行证据证明。
