# 品类适配示例（按需参考）

先使用 [开放品类适配方法](../../brand-profile/references/CATEGORY_ADAPTATION.md) 从本次资料推导；此文件是示范，不是支持范围、品牌路由表或默认交付清单。更换产品线、用户动作与环境后应重新适配。

## 同一方法如何适配不同业务

下表全部为创意推导示范，场景是人为选定的任务前提，不是已有联名。假设合作方提供原创折线图形、日落至夜色的配色及节奏声音；实际合作时应换成对方真实资产。具名品牌不永久绑定这一行的产品：换产品线时重新推导。

| 本次任务前提 | 从本体/体验出发的设计 | 从使用过程推导的候选 |
| --- | --- | --- |
| lululemon，选瑜伽或训练 | 将折线与配色转为选定训练服的图形分区，或瑜伽垫的垫面视觉；节奏资产可成为独立的习练内容提案。衣着和垫面应分别考虑动作及接触位置，不凭概念声明新面料性能或防滑效果。 | 从穿着、习练、携带、清洁与课程参与推导吊牌、垫带/收纳、护理说明、动作场景图、课程内容页及陈列。若选跑步，重新选择跑服、鞋或跑步配件。 |
| 凯乐石，选越野跑山 | 以所选跑山鞋或背心为核心，把图形变成鞋面分区、鞋舌/后跟或背心可见区域的表达，保留已知结构及装备取用。可探索节奏与路线叙事，不声称新增导航功能。 | 从穿着、装备收纳、途中取用与赛后护理推导鞋盒/适配收纳、护理卡、细节图、装备搭配、跑山视觉和展示。改为攀岩任务时改用该任务对应的载体。 |
| The North Face，选徒步背负或山地防护 | 以所选背包或外套为核心，将配色与折线转为外部面片或既有拼接区；围绕装包、取物、分层穿着展示设计。不能仅将上一行换成北面 Logo。 | 推导装包图解、分层穿搭、吊牌、适配收纳、空间陈列与产品详情；不沿用无关鞋盒或跑山活动清单。 |
| 手机厂商，现有直板机限定外观 | 手机后盖、镜头区域周边、配色及材质感是本案设计位。保持已有镜头、按键与接口；系统权限未知时，壁纸可作素材提案，不能承诺已实现系统主题或新增软件。 | 从握持、保护、开箱、设置、展示推导适配壳、盒/内托、说明、壁纸素材、细节图、电商图、体验台。没有屏幕改造权限就不设计新交互功能。 |
| 电脑厂商，先区分笔记本与桌面机 | 笔记本可研究上盖、掌托或已有键盘区域；桌面主机研究机箱可见面、桌面摆放与维护路径。图形不能覆盖散热、接口或需要开启的位置；无屏幕的机箱不能画成带屏笔记本。 | 笔记本从移动办公推导内胆包、收纳和出行展示；桌面机从开箱、布置、接线、维护推导保护包装、接线说明、桌面场景和维护示意。外设按任务范围选择。 |
| 健身器材，先区分器械形态与动作 | 无屏幕动感单车可研究非受力可见面、骑行动作与训练内容；小型训练器材另按抓握、摆放、携带设计。已有屏幕才讨论界面，既有软件能力另核实；不凭外观改变阻力、承重、制动或活动空间。 | 根据安装、首次使用、训练、清洁与场馆体验推导安装/使用说明、护理卡、独立课程封面、场景图与导视；无屏幕器械的内容可由独立媒介承载，不冒充机身功能。 |

## 品类示例：用于提案，不是已确认清单

以下均为可筛选的设计提议，不是外部案例事实、品牌现有 SKU、已确认授权或每次必做清单。角色与色彩系列放进对应物料的变体；每个保留项仍需说明独立用途、双方贡献和本案设计。

| 层次 | MANNER × 游戏：以咖啡为核心 | 酷态科 × 虚拟 IP：以 3C 为核心 |
| --- | --- | --- |
| 主营产品 | 角色主题咖啡，角色特征转为风味、层次、奶泡/装饰及命名；不同角色口味作为该饮品系列变体。挂耳咖啡或咖啡豆组合可另作提议，需明确新增品类依据 | 联名充电宝外观，以壳体、配色、材质感和角色图形体现 IP。充电头、数据线或扩展坞仅在符合本次品类范围时作为独立产品提议，参数保持待确认 |
| 包装与随附 | 杯身、隔热杯套、杯托、咖啡提袋、外带封签、组合礼盒、产品说明小卡；各自承担盛装、隔热、携带、防拆、组合呈现或介绍作用 | 零售外盒、内托、保护包覆、快速使用卡、产品信息/必要安全说明卡、购物袋、组合套装包装；不能在说明卡上编造规格或认证 |
| 传播物料 | 发布主海报、角色风味菜单、点单台卡、取餐提示、社交发布组图、饮品设计介绍折页；不同尺寸海报是变体 | 发布主海报、产品详情长图、设计细节介绍卡、日常使用场景组图、货架介绍牌、开箱内容图；真实性能卖点须有依据 |
| 延伸周边 | 杯垫、可重复使用的随行杯、杯袋、贴纸套组、徽章、钥匙挂件、冰箱贴、书签等，按饮用/携带/收藏用途择取 | 收纳包、理线器、线材收纳带、桌垫、桌面支架、贴纸套组、徽章、钥匙挂件等，围绕携带/整理/桌面/收藏用途择取；挂绳或保护套须核对适配条件 |
| 场景与体验 | 门店橱窗图形、柜台陈列、饮用桌垫、拍照展示装置、风味体验说明；按实际触点择取 | 桌面充电场景陈列、门店体验台图形、开箱展示台、便携出行场景展示；不假定存在额外电子功能或已落实门店装置 |

其他品类按自身产品与使用方式展开，下表示例不限定合作方类型；合作方可贡献审美、工艺、材料、技术、内容或服务。

| 品类 | 核心产品或体验与合作融合 | 可选包装、传播与相关延伸 |
| --- | --- | --- |
| 首饰 | 在品牌实际能力和本次范围内选择吊坠、项链、戒指、耳饰等；将双方符号、材质表达、工艺或结构特点转为造型、组合与佩戴方式。同款尺寸或配色归为变体，不要求一次做全品类 | 首饰盒、内托、便携收纳、擦拭布、保养说明、佩戴效果图、工艺介绍卡、主海报、陈列；贵金属成色、宝石、镀层、过敏相关表述及工艺可行性据实确认 |
| 服饰与鞋包 | 在明确范围内选择服装、鞋或包，将图案、面料、版型、功能和穿着场景形成共同设计，不只添加角色图或 Logo | 吊牌、洗护说明、包装袋、衣架或收纳、穿搭图、系列画册、橱窗；面料性能、尺码和供应能力保持证据边界 |
| 美妆与个护 | 以已确定的彩妆、护肤或香氛为主体，将色彩、气味设想、配方思路、容器和使用方式形成合作提案 | 容器外观、外盒、内托、说明、化妆包、镜子、试色或使用图、柜台与海报；成分、功效和安全结论不能凭概念设定确认 |
| 家居与生活方式 | 在餐具、灯具、纺织品、家具等实际品类中选择，将造型、材料感、工艺、功能和居住场景形成设计 | 保护包装、说明、清洁或收纳配件、空间搭配图、陈列和主海报；不假定品牌能生产全部品类 |
| 数字、内容与服务 | 联名内容作品、主题界面、数字功能、课程、会员服务或线下体验流程，可由双方共同提供；先写清实际功能、内容与消费者过程 | 欢迎页、功能演示、内容封面、参与引导、使用说明、服务触点和传播素材。核心可归入 product 或 experience，不要求包装、徽章、实体赠品或虚拟角色 |

候选数量来自实际用途和范围，核心产物始终居首。配方、材质、电子结构、履约能力等验证在进入相应落地阶段后展开，不作为概念效果探索的前置门槛；效果图或流程示意也不能证明这些条件已验证。
