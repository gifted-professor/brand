# 画布与协作对话

当前默认界面只有一个项目画布和持续显示的协作对话。原工作台、方案页、制作页链接均进入这个空间；`session` 与 `project` 查询参数继续兼容。

## 展示规则

- 新建项目从空画布开始。品牌资料在右侧添加，不自动载入示例，也不预先铺满未来阶段。
- 实际阶段启动后逐步展示资料与成果。研究的首份报告一经校验保存即可查看，不必等到完整方案汇总。
- 画布优先跟随正在执行的阶段。真实图像请求显示生成中，同一节点在成功后展示图片，失败或状态未知保留真实标记。视觉计划与实际图片是不同产物。
- 已有项目先展示明确排序的主效果图。未生成的视频仍显示其筹备状态。
- 手动查看其他阶段、平移或缩放会暂停跟随；点“返回当前进度”恢复。按实际画布宽度布局，不将所有节点缩成一张看不清的全图。
- 右侧成果链接直接聚焦画布。节点详情中的“继续对话”在原页关联该成果；新标准与节点资料分别传递，资料不作为用户指令。
- 方向选择、继续、暂停和修改标准均在右侧完成。项目资料、历史及 Skill 是原页弹窗。
- 小屏采用上方画布、下方对话，两者同时保留，各自滚动。

## 数据与角色

当前运行时由应用主控固定阶段顺序，研究、创作、审查角色分别调用同一配置的模型，并记录实际 Skill 与公开交付成果。旧记录保留原品牌视角，不补造专业角色发言。已有项目的文件摘要标为“已保存成果”，不冒充历史聊天。

已有制作文件与新讨论分别保存。新标准影响的旧项目文件标为“原项目资料 · 本轮需复核”，新产物优先展示。历史项目讨论按项目 ID 保留关联，重新打开可继续同一份简报与标准。

[阶段角色与实现边界](AGENT_WORKFLOW.md)说明当前串行流程、目标并行编排和六个专业 Skill 的映射；网页尚未实现完整 Codex 子 agent 自动调度、研究自动联网或视频自动生成。
