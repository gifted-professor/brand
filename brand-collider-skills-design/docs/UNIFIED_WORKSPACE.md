# 画布与协作对话

当前默认界面只有一个项目画布和持续显示的协作对话。原工作台、方案页、制作页链接均进入这个空间；`session` 与 `project` 查询参数继续兼容。

## 无限画布与图层

- 新建项目从空画布开始。品牌名称在右侧添加即可开始，品类、描述、附件和目标为选填；不自动载入示例，也不预先铺满未来阶段。
- 主控开始整理简报时立即显示“共同简报与任务交接”节点，内容来自用户实际目标、标准及已提交的交接。画布上方持续显示当前动作、简报版本、真实完成步数，展开可查看九个专业步骤；主控交接不虚增专业阶段完成数。
- 实际阶段启动后逐步展示资料与成果。研究的首份报告一经校验保存即可查看，不必等到完整方案汇总。
- 所有已出现成果保留在同一张无限画布上，新增内容不会移动已有卡片；卡片可以自由拖动，坐标、视野与图层显隐按项目保存在本机。
- 左下角“图层”展开主控、研究、创意、设计、文案、生图、视频、审查八类。点击名称只定位，眼睛按钮显隐；展开后可逐项查看成果，连线按需显示。
- 主控暂停、执行失败及手动模式下等待选方向均显示真实状态；一方研究完成而另一方失败时，已保存报告仍可查看。局部自动修复显示当前步骤的修复状态，保留此前已完成成果。
- 画布优先把视野带到正在执行的工作，不通过阶段过滤替换内容。真实图像请求显示生成中，同一节点在成功后展示图片，失败或状态未知保留真实标记。视觉计划与实际图片是不同产物。
- 已有项目先展示明确排序的主效果图。未生成的视频仍显示其筹备状态。
- 手动定位、拖动卡片、平移或缩放会暂停跟随；点“返回进度”恢复。默认镜头聚焦适合当前屏幕的局部；“查看全部成果”提供整体鸟瞰，卡片世界坐标不随屏幕大小变化。
- 右侧成果链接直接聚焦画布。节点详情中的“继续对话”在原页关联该成果；新标准与节点资料分别传递，资料不作为用户指令。
- 默认连续推进九个专业阶段，主控推荐并采用首个方向后继续，不等待用户逐步点击。右侧保留调整方向、继续、暂停和修改标准；项目资料、历史及 Skill 是原页弹窗。API 显式选择手动推进时才停在选向处。
- 小屏采用上方画布、下方对话，两者同时保留，各自滚动。

## 数据与角色

当前运行时通过本地 CLI 启动主控及研究、创作、审查的独立会话；应用保留阶段依赖、校验和共享资料管理，并记录实际进程、Skill 与公开交付成果。旧记录保留原品牌视角，不补造专业角色发言。已有项目的文件摘要标为“已保存成果”，不冒充历史聊天。

已有制作文件与新讨论分别保存。新标准影响的旧项目文件标为“原项目资料 · 本轮需复核”，新产物优先展示。历史项目讨论按项目 ID 保留关联，重新打开可继续同一份简报与标准。

画布上的研究卡不仅列缺口，还须展示当前品牌画像、消费者场景和可供下一阶段采用的依据。只有品牌名时采用明确的工作假设，预算、授权与生产条件留为落地待确认；不能用“资料不足”替代整条概念链路。主控代选方向显示为当前推荐，不冒充用户亲自选定或品牌方批准。

刷新研究通过新简报版本执行：`refreshResearch: true` 会采用当前 Skill 规则重做研究并保留 `pinHistory`。旧资料边界与新概念产物保持版本区别；一次流程完成表示九个专业步骤提交并汇总，不表示所有商业条件已落实或图片已经生成。

[阶段角色与实现边界](AGENT_WORKFLOW.md)说明当前串行流程、连续推进规则和六个专业 Skill 的映射。网页已接入独立 CLI 进程与会话恢复，Grok 研究角色可进行受控公开检索；仍未实现阶段并行或视频自动生成。视觉计划与实际图片始终分开，真实生图仍需独立制作调用。
