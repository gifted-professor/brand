## 使用方式

1. 拖动画布空白处或使用滚轮平移；按住 Command / Control 使用滚轮缩放，也可使用右下角按钮。
2. 拖动节点整理位置。视角与位置按项目保存在当前浏览器，刷新后保留；「重排节点」恢复默认排列。
3. 点击左侧泳道导航定位；按方向或内容类型筛选。点击节点查看完整内容、真实媒体、上下游依赖和来源文件。
4. 点击「围绕这个节点继续对话」，将已有品牌资料、方案和制作上下文带入一个新的真实模式会话。在第三方输入框追加要求后开始讨论。导入本身不调用模型，不伪造源任务的历史发言，也不改变源任务的选案状态。
5. 页面可见时每 15 秒读取一次制作项目，或点击「同步产出」。新文件会加入画布；源文件不会被画布改写。

## 继续接入新物料

同一项目的制作任务在 `campaign-kit-<名称>/manifest.json` 中登记 `materials[]`，保留稳定的 `materialId`，用 `dependsOn` 指向其他物料 ID。每个物料的 `files[]` 使用相对制作包的路径，并记录 `executionStatus`、`reviewStatus` 与 `selectionStatus`。

可以用 `primaryFile` 指定节点主图，用 `files[].priority` 区分 `primary`、`supporting` 和 `appendix`，并在 `primaryDisplayOrder` 中排列物料 ID。画布优先呈现主效果图，来源原图与结构附录仍可在详情中查看。`reviewed_with_limits` 显示为已审阅并保留限制，不等同于全部通过。

支持实际图片、视频、音频、文档和下载包。图片显示预览，视频与音频提供播放器；服务端支持媒体 Range / HEAD 请求。生成原图已经落盘但尚未登记到物料时，显示为「待归档与审查」，不猜测它属于哪张物料。

此画布目前提供查看、整理、下载与带入对话。它不在节点上直接发起新图或视频生成；已有生图 API 与品牌对话入口仍然可用。

## 本地实现

- `src/server/production.ts`：只读文件适配、当前状态映射、素材响应和讨论资料导入。
- `web/components/ProductionWorkspace.tsx`：项目选择、自动同步与导入。
- `web/components/ProductionCanvas.tsx`：画布交互、依赖连线、节点详情和媒体预览。
- `web/session-production.ts`：当前会话到制作节点的映射。

API 入口为 `/api/production/projects`。目前只公开已明确接入的项目目录；资产 URL 使用服务端登记的 ID，不接受任意文件路径。目录越界、敏感文件名、无效媒体及未完整写入的文件不会成为可用素材。清单写入期间会暂用最近一次完整 JSON，并重新核对每个实际文件。

使用 `npm run build` 检查编译，`npm test` 执行测试。制作接入测试覆盖清单更新、无视频时的状态、资产下载与 Range、安全文件边界，以及不调用模型的真实资料导入。
