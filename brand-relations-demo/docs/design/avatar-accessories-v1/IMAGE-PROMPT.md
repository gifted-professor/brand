# Base avatar asset

Method: built-in image_gen, reference-preserving generation with transparent alpha. Original input and generated source are preserved. The in-app accessory layer is procedural SVG; this is not a rigged 3D character or an independently generated 3D accessory library.

Output: `public/avatars/base-reference-v1.png`

Prompt:

Use case: identity-preserve. Create a production sprite for a brand collaboration app using the attached character as the exact visual reference. One single full-body soft 3D chibi character, same friendly face, rose-brown swept bob hair, cream knit beanie, clear amber glasses, slate blue shirt, dark knitted vest, olive neutral cross-body small bag, wide taupe trousers, cream sneakers. Preserve face, outfit, proportions and pose. Both entire feet and hat fit within the canvas with a small transparent margin. Full-body front slight three-quarter view, hands relaxed close to body so equipment can be overlaid later. No extra capability equipment, no symbols, no text, no logos. Remove the warm studio background completely; genuinely transparent alpha background, no checkerboard drawn, no platform or floor. Soft premium 3D materials and subtle contact shading only on the character itself. Center the figure on a portrait canvas, occupying 90% of height. This is one clean reusable base character asset, not a poster or UI.
