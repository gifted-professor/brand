# 品牌 IP 与能力视觉标准 V0.3（设计提案）

日期：2026-09-05。本文定义下一轮实现契约；不是已上线功能，也不是已通过用户研究的视觉编码。

## 目标

同一品牌跨系列仍能被认出；不同品牌保留自己的形象；用户通过统一的视觉表达理解行业方向、主要贡献与当前寻找的合作。角色不承担品牌实力排序或合作成功预测。

参考 POP MART 的系列化方式：官方将 LABUBU 的尖耳与九颗牙列为辨识特征，同一 IP 下又有不同主题与合作系列。我们据此提炼“稳定身份锚点 + 可变化主题层”的设计方法，不复制其具体角色。

- 官方 IP 介绍：https://www.popmart.com/at/ip/the-monsters/efc371ce-c7dc-4d71-a820-136113d96587
- 官方系列目录：https://www.popmart.com/us/collection/11/the-monsters

同时对齐 `outputs/brand-understanding-case-audit-20260905/品牌发现与合作流程V0.2.md`：Avatar 来源于用户确认的品牌理解；品牌属性与两品牌关系分离；未知不是低分；当前目标不等于已有能力。

## 1. 三层设计，不共用一张脸

| 层 | 解决的问题 | 固定内容 | 允许的变化 |
| --- | --- | --- | --- |
| 品牌母型 | 这是哪个品牌 | 主体轮廓、脸部结构、关键比例、2–3 个识别特征、品牌标记、主色规范 | 仅经品牌明确选择的新母型版本更新 |
| 能力表达 | 能为合作带来什么 | 能力类别的符号含义、已有/寻找的区别、主要能力的呈现优先级 | 工具的适配造型、附件尺度、经确认的能力内容 |
| 系列主题 | 同一品牌如何有新表达 | 母型识别锚点、能力陈述 | 服装、配件材质感、局部纹样、动作、季节与项目主题 |

标准约束含义与可读性，不要求所有品牌共用一个人形模型。人、动物、植物、器物都可以成为母型。没有手的品牌形象可以使用侧挂工具模块，不能为适应模板强行给已有 IP 增加肢体。

## 2. 首次生成与后续出款分开

### 首次建立 IP

1. 输入名称、公司介绍、已有能力、当前目标；可补充现有吉祥物、Logo、色彩与视觉规范。
2. AI 归纳品牌快照，用户确认关键描述。能力是否存在、是否愿意投入本次合作分别记录。
3. 已有吉祥物：保留授权素材中选定的脸、轮廓与标记，提出三个系列化表达。没有吉祥物：先提出三个母型方向，供品牌选择一个。
4. 用户确认母型，保存带版本号的角色参考资产、识别锚点和允许变化范围。
5. 基于选定母型生成三个主题候选。选择一个进入 Gravity 和抽卡。

### 后续系列与更新

- 换主题：固定母型与能力快照，只改变主题层。
- 修改已有能力：确认能力变化后更新能力装备；不自动改脸。
- 修改当前合作目标：只更新状态标记；不重新生成母型。
- 切换 Gravity Focus：仅改变关系场，不改变该品牌角色的能力、脸或比例。
- 品牌主动更换 IP：明确创建新的母型版本，旧素材和旧版本仍保留。

只保留随机种子不能保证连续生成的一致性。AI 生成应同时使用锁定的参考资产、固定区域和结构约束；输出仍需相似性检查与品牌确认。

## 3. 统一的可读标准

用户第一次看到陌生品牌，合理目标是读出大类与主要贡献，而非从身体尺寸解码完整公司资料。

| 信息 | 建议表达 | 例子与限制 |
| --- | --- | --- |
| 品牌身份 | 母型轮廓、品牌色、识别特征 | 保持叶冠、方块头或自有吉祥物；颜色不能同时被强制用于能力编码 |
| 行业方向 | 一个熟悉的行业物件或产品轮廓 | 茶杯、面料卷、材料试片；只说明业务大类，不等于全部能力 |
| 可提供的主要能力 | 一个主要工具，最多两个辅助模块 | 设计用绘制/构造工具，生产用加工工具，渠道用运输/节点模块；搭配简短能力词 |
| 正在寻找的能力 | 与装备分离的可拆状态标签 | 明示“寻找渠道”，不能把渠道工具直接画成已拥有 |
| 详细证据与条件 | 点击后的资料层 | 能力原文、适用项目、可提供范围、时间与限制；不把所有字段塞进角色 |

优先采用熟悉的工具隐喻，并对难理解的类别保留标签。统一的位置是默认布局，已有 IP 可以换挂载位置；已有/寻找的区分和符号含义必须保留。

### 能力词汇与六个主题组

当前六组可以继续作为 Assets 的展示分类：设计研发、生产交付、数字技术、渠道空间、社群活动、文化内容。每组可展开为具体能力，例如材料研发、包装、小批量制造、软件开发、出版或活动策划。

这六组不是 Brand Understanding 的六个一级因子，也不是六个强弱分数。不应因为一个品牌没有某组描述就画小、画残缺或画暗。

## 4. 六因子如何进入角色

| 品牌理解因子 | 使用位置 | 不允许的推导 |
| --- | --- | --- |
| Identity | 母型、品牌语气与视觉规范 | 不能因一个词就冒充现有品牌吉祥物 |
| Audience | 可选的使用场景与作品情境 | 不用粉丝数量决定体型；不根据消费者群体丑化角色 |
| Assets | 已有能力工具与模块 | 有资产不等于愿意投入，也不等于有权公开所有材料 |
| Intent | 可更新的目标与寻找标签 | 想做某事不等于已经会做 |
| Execution | 具体交付方式与适用项目的说明 | 公司大不等于这个项目可交付；工具尺寸不是产能估计 |
| Constraints | 详情中的适用条件；必要时显示明确状态 | 不把限制画成难看或劣等的品牌形象 |

公开角色只使用确认可公开的描述与视觉素材。证据可以区分品牌自述、模型推断、未知；品牌确认自述不等于外部事实核验。

## 5. 大小长短改变哪里

优先保留脸、躯干和关键比例，将变化集中在工具、头饰附件、背包、披风与侧挂模块。尺寸表达某一能力在当前展示中的侧重，不宣称客观实力。

- 不采用“头大=设计强”“腿长=渠道强”作为唯一编码。这些关系需要学习，且会破坏品牌母型。
- 使用“基础 / 标准 / 强调”三档视觉状态先验证可读性，避免让用户解释 30.1 一类造型数值。
- 每个母型单独定义允许的附件边界，不能用一套比例强行适配所有 IP。
- 未知保留中性完整造型与“待补充”说明；不使用残缺、暗淡或稀有度区分品牌价值。
- 同一品牌的不同主题不改变已确认的能力侧重，除非品牌主动选择不同的展示重点并明确标注。

## 6. 两个虚构品牌的系列示例

以下是说明机制的设计假设，并非实际已生成、已拥有的品牌资产。

| 品牌 | 母型锁定 | 能力线索 | 可发展的系列 |
| --- | --- | --- | --- |
| 苔屿 Moss Isle | 双叶冠、豆形脸、苔绿主色、陶土色小标记 | 设计工具 + 层叠材料试片，文字“设计 / 材料研发” | 材料实验室、林间探索、冬日工作室：同一张脸与叶冠，改变服装、纹样和姿态 |
| Memory Block | 方块轮廓、缺角标记、固定眼距与品牌主色 | 同一设计符号 + 原型模块，文字“设计 / 原型” | 日常工作、模型工坊、展览现场：保留方块母型，改变服装和场景 |

两家品牌均能提供设计：共享设计符号的含义，但母型明显不同。苔屿需要渠道时使用“寻找渠道”的状态标签，不能由主题服装生成出新的渠道能力。

## 7. 生成和渲染契约

建议将当前平铺的 recipe 拆分为：

```text
brand_snapshot_version
identity_asset
  identity_version
  reference_assets
  locked_features
  brand_palette
  allowed_attachment_zones
capability_display
  confirmed_assets
  primary_asset
  secondary_assets (0–2)
  evidence_status / evidence_refs / public_visibility
  emphasis_preset
current_state
  goals / seeking / updated_at
edition
  edition_id / theme / outfit / pose / surface_treatment
render_assets
  detail_asset / compact_asset / marker
```

AI 负责品牌解读和主题创作。程序负责固定身份、能力映射、已拥有/寻找的区分和比例边界。不能仅依赖一段“保持一致”的提示词。

母型素材有两条渲染路径：参数化角色使用分层矢量；已有复杂 IP 使用用户确认的透明图与可挂载附件，并导出不同分辨率。生成发生在录入或更新时，关系场复用已保存素材；远景继续使用 LOD。风格不限定为半色调。

## 8. 验证标准（拟定目标，尚未验证）

使用 12 个母型，每个 3 个主题，覆盖相同能力不同品牌、同品牌不同主题、未知信息、已有与寻找的对照。

1. 同族识别：隐藏名字和 Logo，参与者将主题变体按同一角色分组；目标正确率至少 85%。
2. 能力识别：短暂展示图例后，在未见过的角色上判断主要贡献大类；目标正确率至少 75%。同时测未经学习的首次理解，不混报两种结果。
3. 状态区分：判断“拥有渠道”还是“寻找渠道”，目标正确率至少 90%。
4. 品牌辨识与审美：品牌代表确认锁定特征保留；多名目标用户评价各主题是否协调，分别记录最差候选，不只报告平均值。
5. 关系独立：同一资料更换主题前后，关系分数与空间坐标保持不变。
6. 极端与缩小：所有允许的附件组合都完整、无穿插；在关系场实际显示尺寸下，主能力符号和必要短标签仍能读清。

达不到识别目标时，优先改符号、减少同时展示的信息或补充标签，不通过加大体型或增加炫目特效来掩盖问题。

## 9. 当前 Demo 的明确差距

- 已有三种轮廓候选、参数化 SVG、资料引用和保存流程，可以复用。
- 目前每次候选会更换头部轮廓，应拆成首次选母型与后续选系列。
- 暂无现有 IP 上传、参考资产锁定与真正的主题系列生成，不能声称已经保留用户自有 IP。
- 当前六部件主要表达 Assets 分类；尚未完整接入六因子理解和用户确认。
- 现有数值比例只证明几何可渲染，尚未证明陌生用户能正确读出能力。

下一轮实现顺序：母型确认与锁定 → 已有素材入口 → 统一能力模块与状态区分 → 同母型三个主题 → 识别与审美验证。
