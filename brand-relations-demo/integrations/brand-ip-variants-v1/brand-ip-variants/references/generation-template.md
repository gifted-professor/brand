# 品牌换装生成模板

在实际生成或用户要求提示词时读取。按本次任务删减，不必向用户展示整张工作表。所有可选值都是待填参数；未提供时遵循 SKILL.md 的默认规则，不能把括号占位文字传进生图工具。

## 提示词骨架

```text
Use case: identity-preserve
Asset type: 同一角色的品牌 IP 全身形象

输入图片角色：
- 图 1：原始角色本体，脸部、身体比例、发型基础轮廓与 3D 渲染质感的身份依据。
- 图 2 及以后：逐张写明用途。已确认版本仅用于继承服装/构图；品牌或产品图仅用于对应物料，不用于改变角色长相。

任务：编辑图中的同一个角色，为【品牌或方向】制作【本轮修改范围】。

必须保持：
原本体的圆润脸型和脸颊、小下巴、深棕大眼睛的轮廓与间距、眼睑、眉形、小圆鼻、轻微闭嘴笑、耳朵形状、暖桃肤色，以及头相对身体的大小、肩宽与四肢体量。保留原图精致柔和的 3D 玩偶质感。
头发保持原图的偏分蓬松短发、侧扫刘海与微翘发尾；发色按下文调整。如用户明确指定另一发型，用该要求替换这一句，其余身份约束保持。

本轮变更：
- 服装与鞋包：【款式、层次、面料、颜色】。
- 手饰：【种类、颜色、佩戴位置；未改变则写保留】。
- 手持物：【物品外观、合理尺寸、与手部的接触和握持关系】。
- 发饰与耳饰：【外形、材料、颜色、位置，避免遮挡主要五官】。
- 发色：【具体颜色、是否局部挑染；不连带改变肤色与眼睛】。
- 品牌元素：【准确图形参考、用色和放置位置】。

保留：【本轮不应变化的已确认内容】。
移除：【本轮被替换的旧衣服、包带、包袋或配件；没有则省略】。

构图与光线：
默认单个角色完整站立，继承本体视角与放松姿态，只有握持需要时局部调整手臂。竖向约 4:5 画幅，角色居中，发顶与鞋底完整，暖米白简洁背景，柔和棚拍光线与自然接地阴影。按用户明确的画幅、背景和姿势要求覆盖相应部分。

Text (verbatim)：【只在用户需要图片内文字时填写，逐字准确】。

避免：
改变人物长相或头身比例；把角色成人化、写实化或平面化；皮肤染上品牌色；配件遮住主要五官；重复手臂或道具、手与物品融合、悬空饰品；需要移除的旧装备残留；无要求的第二人物、标题板、水印与其他品牌标志。
```

实际请求是局部修改时，删除不相关的“本轮变更”条目，明确其他内容保持，不借模板扩展范围。

## 后续修改模板

```text
图 1 是原始本体，只负责确保身份和比例；图 2 是用户已确认的品牌版本，也是本轮编辑目标。
仅修改图 2 的【具体部位】为【新要求】。
保留图 2 的【已确认服装、发色、其他饰品、道具、背景和姿态中的适用项】。
脸型、五官与头身比例继续以图 1 为准。不要把图 1 的旧衣服和旧配件带回图 2。
【若修复上一版偏差，写出可观察的问题及正确关系，例如手指自然绕住杯柄且杯子不穿过手掌。】
```

## 使用示例

- “用这个本体做山野咖啡的 IP，苔绿围裙，手拿奶白咖啡杯，发色改栗棕，加一枚叶形发夹。” → 直接做一张完整品牌换装；品牌按用户给出的创意方向处理，不虚构官方规范。
- “保留上一版，只把手表换成银色手链。” → 以本体与上一版双参考，仅改手饰；不能把已经改好的服装和头发恢复成原图。
- “做同一品牌的三种配色，分别出图。” → 三张独立图片共用本体和服装设计，只改变约定的配色范围。
