# 品牌 IP 配饰与能力评价表

版本：2026-09-06 · v1

配饰用于识别品牌陈述的产品、工具与能力。五官和身体比例保持原型；发型与发色随品牌身份变化，不参与评分。手持物表示主要产品/工具，随身装备表示辅助能力/资源，内容挂件表示补充内容。配饰的位置与数量没有分数权重，金色、体积或复杂度不代表更强。

此表是可复核的评价规则，不是品牌认证。40 家示例公司为虚构数据，不含真实核验结果。当前应用的引力排序仍是规则估算；下文证据评审是进一步评估标准，不代表已对每家公司执行。

## 1. 配饰对应什么，怎样量化

先明确本次项目的需求、单位、目标值、时间和测试条件，再记录实际值及来源。仅有产品外观不能证明量产、服务或认证能力。

| 配饰 | 对应能力 | 需要核对的依据 | 建议记录的指标 |
|---|---|---|---|
| 茶壶 | 茶产品与茶事体验 | 产品清单、可供批次、茶事案例 | 可供数量 / 需求数量；场次承载人数 |
| 咖啡杯 | 咖啡产品与咖啡体验 | 烘焙批次、供货记录、活动方案 | 每周可供 kg；每小时出杯数；活动到场率 |
| 陶器 | 陶艺设计与制作 | 实物样品、工艺说明、交付记录 | 合格率；起订量；打样和交付天数 |
| 相机 | 影像拍摄与内容制作 | 署名作品、制作分工、可用档期 | 约定周期可交付条数；验收通过率 |
| 监听耳机 | 声音设计与后期制作 | 声音作品、制作说明、素材使用范围 | 可交付音频分钟数；格式与场景覆盖率 |
| 录音机 | 录音采集与声音记录 | 采集样例、设备与人员、可用档期 | 采集时长；有效录音比例；场景覆盖数 |
| 纱线 | 纺织与针织开发 | 样布、成分与工艺、可投入产能 | 可供米数 / 需求米数；色牢度等约定指标 |

| 书籍图录 | 出版或文化内容 | 目录、内容样章、出版或使用权限 | 可用内容量；约定渠道实际触达；交稿周期 |
| 交互终端 | 数字交互与软件体验 | 可运行演示、功能范围、维护责任 | 关键任务完成率；响应时间；承载人数 |

| 包装盒 | 包装设计与供应 | 包装样品、结构测试、报价与产能 | 单件成本；破损率；打样天数；供货量 |

| 面包 | 烘焙食品开发与供应 | 菜单、批次、适用供货条件 | 每日可供份数；损耗率；约定时段供货率 |
| 滴管瓶 | 香氛或护理产品开发 | 配方方向、样品、适用用途与测试 | 试样周期；盲测偏好率；可供批次量 |
| 玻璃容器 | 玻璃器物与材料工艺 | 实物样品、来源与工艺、测试记录 | 良品率；约定性能达标率；交付周期 |
| 灯具 | 灯具设计与灯光体验 | 灯具样品、光学参数、适用使用条件 | 照度 / 功耗等目标达标率；安装工期 |

| 户外装备 | 户外装备或场景支持 | 装备样品、适用条件、活动案例 | 目标场景覆盖率；可供套数；响应时长 |
| 食材茶篮 | 食材、茶或咖啡原料采购 | 来源、可供批次、质量与交付约定 | 批次可追溯率；可供量；损耗率 |
| 植物与材料标本 | 植物或材料样本研究 | 样本清单、实验条件、可复查记录 | 可用样本数；试验重复性；验证周期 |
| 拓印章 | 拓印与印制工艺 | 拓印样品、版式与材质、制作范围 | 约定精度达标率；每小时产出；换版时间 |
| 便携音箱 | 音箱产品或扩声体验 | 型号或方案、场地条件、声音测试 | 目标面积覆盖；清晰度达标率；可用套数 |
| 扫码器 | 扫码设备或识别流程 | 设备演示、码制范围、接口与测试 | 识别成功率；单次耗时；流程完成率 |
| 太阳能板 | 太阳能产品与发电模块 | 具体样品、测试工况、可用接口 | 约定工况输出 W；转换表现；供货期 |
| 储能电池 | 便携储能与供电 | 型号、测试工况、使用与维护范围 | 可用 Wh；续航小时；目标负载覆盖率 |

指标的方向要逐项判断：准时率、达标率通常越高越好；差错率、破损率和约定响应时间通常越低越好。产能和触达量以满足本次需求为准，不以规模最大为准。

- 需求覆盖率 = 满足的已约定需求项 / 总需求项 × 100%。关键需求单独列出，不能靠大量次要项掩盖缺口。
- 准时率 = 按约定时间完成的交付 / 应完成的交付 × 100%。同时记录观察期与样本量。
- 达标率 = 在相同测试条件下达标的样本 / 全部测试样本 × 100%。
- 可投入产能比 = 本项目确认可分配的产能 / 项目需求。达到需求后，超额产能不自动加分；纸面总产能不能代替已确认可投入量。
- 不把这些不同单位的指标直接相加，也不把某项 80% 自动当成合作评分 80 分。

## 2. 什么代表分数较高

评分对象是双方在具体项目中的合作潜力，不是单个角色的实力。先写依据、反证和未知，再在下面区间内给 0–100 分；1–2 分的差异没有已验证的商业意义。

| 维度 | 权重 | 低：0–39 | 中：40–69 | 高：70–100 | 未知：null |
|---|---:|---|---|---|---|
| 目标契合 | 35% | 当期目标或时间明确冲突 | 存在交集，范围仍需协商 | 具体方案分别服务双方明确的当期目标 | 缺少目标、时间或优先级 |
| 能力互补 | 30% | 配饰对应的能力没有补足需求，或角色重复 | 有单向补足，或具体投入待确认 | 双方可投入的能力分别填补对方关键缺口，路径明确 | 只有能力宣传，无法确定可投入范围 |
| 受众拓展 | 15% | 没有合理的新触点或目标场景 | 存在相邻人群假设，进入路径待验证 | 有进入新目标人群或场景的具体路径与依据 | 受众构成或触达关系不明 |
| 创意共鸣 | 15% | 表达冲突且没有共同叙事 | 方向可共存，但产物和共同表达仍抽象 | 组合形成具体、易理解且有价值的表达或反差 | 只知道行业、发色或性格标签 |
| 执行可行 | 5% | 证据表明当前规模、工期或必要条件无法满足 | 部分可交付，关键环节仍待补齐 | 当前规模、工期、负责人、承载与维护都有对应证据 | 没有执行证据，不默认高分 |

总分 = round(目标契合 × 0.35 + 能力互补 × 0.30 + 受众拓展 × 0.15 + 创意共鸣 × 0.15 + 执行可行 × 0.05)。权重沿用项目基线；它是探索偏好，不是统计验证的成功概率。

**关键维度没有证据时，该维和总分均填 null（待核实）。** 不用 0 代替未知，不默认执行 91，不重新分配权重。明确的必要条件冲突单独标为当前方案受阻，不能被高总分抵消。

### 虚构算例：咖啡杯 × 包装盒

配饰显示咖啡体验与包装供给。只有咖啡品牌需要包装，是单向补足，尚不足以支持互补高分。若资料进一步说明：咖啡品牌需要 200 套可重复使用包装，包装方需要真实咖啡场景完成试点；双方确认样品、200 套投入、6 周档期、负责人、费用与使用范围，才有双向互补高分的依据。数字仅演示，不是这些公司已承诺的事实。

假设评审在已有证据下分别给出 80 / 85 / 70 / 75 / 80，则总分是 **79/100**。若执行资料缺失，最后一维为 null，总分也为 null。咖啡杯或包装盒本身都没有 85 分。

## 3. 能力依据怎么标注

| 状态 | 含义 | 对分数的影响 |
|---|---|---|
| 品牌陈述 | 来自资料中的自述 | 可识别配饰；不等于独立核验 |
| 有来源可核对 | 附原文位置、样品/案例、时间与适用范围 | 评审人检查它是否支持本次项目判断 |
| 品牌确认 | 有明确主体对具体投入、时间和范围的确认 | 只在该范围内使用，不能扩大为全面认证 |
| 推断 | 由线索推演，附推断理由 | 不能冒充品牌确认；关键证据不足时仍为 null |
| 待核实 | 没有足够依据 | 保留未知，不画勋章或自动填高分 |

视觉编码建议：角色只显示能力类别；打开详情后用以上文字状态与来源表达证据。高分用评价面板中的明确数字和依据表示，不通过稀有发色、发光配饰或豪华装备暗示。

## 5. 视觉技能与原型

采用用户提供的 brand-ip-variants 技能；原包与本体均保留。项目继续使用此前确认的 public/avatars/prototype-v1/reference.jpg 作为五官和身体基准。每个新品牌直接引用同一本体；新发型、发色、服装与配饰不能替换五官或改变身材。配饰仅从品牌当前自有产品/能力陈述产生，不把“希望获得”“不具备”“合作方提供”画成自有能力。

本轮为 40 家虚构公司保存独立技能设计记录。图像生成样例另附实际提示词及成图；这些记录不冒充已生成的 40 张图片。
